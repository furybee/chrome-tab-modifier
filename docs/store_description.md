Take full control of your browser tabs with Tabee! Rename, organize, and customize your tabs effortlessly with powerful automation rules.

✨ Key Features:

🏷️ Smart Tab Renaming
- Rename tabs with custom rules using URL patterns
- Extract text from page elements with CSS selectors
- Join the text of every matching element with |all (e.g. all the tags of a search)
- Use regex patterns for advanced title matching
- Right-click "Rename Tab" for quick renaming, keeping the tab's group, pin and protection
- Titles stay applied on single-page apps like GitHub

🎨 Visual Customization
- Change tab icons easily (paste images directly!)
- Custom favicons for any website
- Support for emoji, URLs, and base64 images
- 7 themes for the options page, including the Tabee theme

📁 Organization Tools
- Group tabs by color and label
- Pin important tabs automatically
- Protect tabs from accidental closure
- Enforce unique tabs (auto-close duplicates), even per ticket or issue number (e.g. one tab per GitHub issue)
- Mute noisy tabs

⌨️ Toggle Rules with Keyboard Shortcuts
- Assign a rule to one of 10 shortcuts, and choose your keys in chrome://extensions/shortcuts
- Rules sharing a shortcut are switched on and off together
- Applied to open tabs right away, no reload needed

🍯 Tab Hive - Auto-Close Inactive Tabs
- Automatically close tabs after a period of inactivity
- Send any tab to the Hive from the right-click menu
- Save closed tabs for easy restoration
- Search and restore from the side panel
- Grouped by domain for better organization
- Exclude domains or URLs from auto-closing

🌐 Side Panel Integration
- Quick access to add rules
- Browse and restore closed tabs
- Real-time tab management

🔍 Spot Search - Quick Tab & Bookmark Finder
- Instant search across all open tabs and bookmarks with Alt+Shift+E (or Cmd+Shift+E on Mac)
- Real-time filtering as you type - search by title, URL, or tab group name
- Keyboard navigation - use arrow keys (↑↓) to navigate, Enter to select, Escape to close

🪟 Windows Merger
- Merge all browser windows into one with Alt+Shift+W (Option+Shift+W on Mac)
- Also accessible via right-click context menu
- Change or remove the shortcut in chrome://extensions/shortcuts

💾 Backup & Sharing
- Export and import all your rules and groups as a JSON file
- Copy a single rule to the clipboard to share it, and paste it to import it

⚡ Performance Mode
- Lightweight mode: turn Tabee off on specific domains or URLs
- Reduce memory usage on resource-heavy sites

🔐 Privacy First
- Open-source and transparent
- No data collection
- All rules stored locally on your device
- ReDoS attack protection

🔧 Advanced Features:
- URL fragment matching (CONTAINS, STARTS WITH, ENDS WITH, REGEX, EXACT)
- Title matcher with capture groups (@0, @1, @2...)
- URL matcher with capture groups ($0, $1, $2...)
- Dynamic title updates with page changes
- Keyboard shortcuts for common actions

🔒 About Permissions:
Access to all websites is required to update tabs as you browse. We respect your privacy - no data is collected or transmitted. All your rules and settings remain on your device.
